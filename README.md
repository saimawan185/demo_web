## Develop locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/demo_web/](http://localhost:3000/demo_web/)

## Deploy

```bash
npm run build
```

Upload the `out/` folder, or push to `main` (GitHub Actions) / `gh-pages`.

Configured with `basePath: /demo_web` for GitHub Pages project site.
